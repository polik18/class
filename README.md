# 智慧課堂助手 (Smart Classroom Assistant)

這是一套為教師量身打造的單頁式（Single-Page）數位教室教具整合包。完整功能統一由 `index.html` 提供，將課堂經營必備的核心工具與 IRS 即時問答整合在同一入口。

## 📂 檔案目錄結構與版本說明
* `index.html`：正式版唯一入口，具備抽籤、時間管理、計分、白板、資料匯出入與 IRS 即時問答。
* `exam.html`：考場資訊大螢幕，可由正式版的時間管理功能進入。

## 🌟 核心功能導覽

**🎯 抽籤機與隨機智慧分組 (Random Picker & Auto Grouping)**
* 支援抽取號碼/姓名。能設定單次抽出數量與「不重複抽籤」。
* 內建「進階隨機分組功能」，只需輸入每組人數與分組方式，系統會直接算出分組結果並帶入計分板。

**⏰ 升級版：時間管理大師 (Time Master)**
* **考試大鐘 (全新升級)**：不僅包含傳統精確到秒的滿版大鐘，還支援自訂輸入「考試科目、考試時間(24小時制防呆自動補零)與監考老師」。內建考場人數（應到/實到）統計，並會即時為您自動計算缺考人數！
* **考試專屬全螢幕廣播模式**：專為考場情境打造的一鍵全螢幕按鈕。點擊後可自動隱藏所有設定列與頂部面板，只呈現最純淨的大鐘與考試重點資訊給全班學生看，提供不被干擾的沉浸式廣播效果。
* 有實用的「小組倒數計時器」，附帶 1、3、5 分鐘極速按鍵。
* 提供輪迴式「上下課鐘」校園響鈴，以及具備布穀鳥動畫與滴答音效的「25分鐘讀書番茄鐘」。

**🏆 計分板與噪音偵測系統 (Scoreboard & Noise Tracker)**
* (核心特色) 計分板附帶**全班噪音偵測**。打開麥克風讓系統聆聽班級音量，一旦過於吵雜超過您的紅線標準（系統滑桿自訂），系統會自動懲罰扣分；如果整班維持圖書館層級的安靜數十秒，系統會自動給予正增強加分獎勵！
* 可以點開各小組，針對組內的「每一位同學獨立加分/扣分」，個人成績會加總至整個小組成績，雙軌並行計算。

**📱 IRS 即時互動系統**
* 老師建立教室代碼後，學生可用平板或手機掃描 QR Code，「無須安裝 App」即可加入課堂。
* 老師出題學生按系統回報。學生加入教室等於完成自我點名，並會把姓名與性別資料推入給抽籤池。
* 可點擊「螢幕廣播」按鍵，將老師的簡報畫面不透過投影機，用區域網私底投射到學生所有的平板畫面上。

## ⚠️ 使用須知與限制條件 (Usage Guidelines)
本系統以瀏覽器本機運作為主；IRS 優先使用 WebRTC 點對點連線，並可透過 Cloudflare 服務協助配對與備援。為確保順利運作，請了解以下須知：

### 1. WebRTC (IRS) 最大連線人數與環境要求
* IRS 優先使用 WebRTC 點對點連線技術；混合傳輸仍在分階段驗證。
* **推薦人數上限**：大約在 **30 - 50 名學生之內**是最穩定的。一旦一次性連入的裝置突破 60 台，老師端電腦（主機）的瀏覽器需要大量的 CPU 及頻寬處理每一條線，可能會產生系統卡頓或斷線。
* **學校防火牆限制**：WebRTC 協定非常容易被某些中小學極嚴格的防火牆或 MIS 阻擋。若您發現「產生不出連線代碼」或「學生打入代碼一直轉圈圈進不來」，極大機率是您校內的網段封鎖了 P2P UDP 連線通訊埠。

### 2. 關於資料保存
* IRS 教室、題目與答案會保存在老師目前使用的瀏覽器中，重新整理時可嘗試恢復。
* 仍建議定期使用右上角的「資料管理中心」匯出備份；更換電腦、瀏覽器或清除網站資料後，本機內容不會自動跟著移動。

### 3. 計分板「噪音偵測」敏感度調校
* 此功能深受老師電腦硬體影響（內建麥克風距離嘴巴多近、雜音抑制強度）。
* **使用建議**：一開始使用務必把 Threshold (達標線設定) 往右拉寬容度高一點。並先確保您瀏覽器的權限已經允許麥克風存取！

## 🔧 故障排除地雷區 (Troubleshooting)
| 症狀描述 | 行動與解法排除 |
| :------- | :--- |
| **學生無法從手機連線至 IRS (無限打轉)** | 1. 確認學生是否打錯網址與代碼。<br>2. 要求幾位連不上的學生**「關閉學校 Wi-Fi，改用自己的 4G/5G 行動網路」**。如果行動網路能登入，就確定是貴校防火牆擋住了 WebRTC。<br>如果是防火牆擋住，這套系統就難以在該教室網路推行連線。 |
| **老師畫面按「連接」跳不出 QRCode 或顯示 Error** | 通常是公用網段阻擋了對公共 STUN 伺服器的請求。老師端可以改借用手機開熱點來避開資安阻擋器。 |
| **開啟噪音系統，但音量表永遠在 0% 沒在跳？** | 您可能禁用了網頁麥克風權限。解決方案：點擊網址列最前端的鎖頭/設定符號，將麥克風權限從「封鎖」手動調整為「允許」，然後再按畫面「開啟麥克風」按鈕即可。 |
| **抽籤機無法跑「不重複抽籤」？** | 請確認您的「抽取總數」是否大於全班總人數。如果班上只剩 5 人沒被抽過，您卻設定一次抽 6 人，因為啟用「不重複」是不可能達成的，系統會報錯提示。 |

## 🚀 如何使用
1. 用個人電腦（筆電佳）的 Chrome/Edge 瀏覽器開啟 `index.html`，公開網址為 `https://polik18.github.io/class/`。
2. 頂部提供全功能的導覽列，一鍵即可快速在抽籤、計時、計分之間順滑切換。
3. 第一次建立學生名單後，建議點擊右上角「資料管理」將備份下載保存，之後每堂課可直接匯入使用。
