# 智慧課堂助手 (Smart Classroom Assistant)

這是一套為教師量身打造的單頁式（Single-Page）數位教室教具整合包。分為「基礎版 (`index.html`)」與「Pro進階版 (`pro.html`)」，將課堂經營必備的 5 到 6 大核心工具完美整合在一起。

*   **平行的基礎組件庫（基礎版）**：把每一個教學功能當作獨立的 App 看待，您可以自由在上方導覽列快速切換，不會互互相干擾。
*   **網狀交織的 Pro 組件庫（進階版）**：這具備強大的**連動生態系**。學生於 IRS 模組登入，資料可自動匯入至抽籤機；抽籤機進行隨機分組時，則能將分好組的名單連動至計分板自動產出卡片，一條龍完整打通。

## 📂 檔案目錄結構與版本說明
* `index.html`：**基礎版**。穩定、無須連網也能完整使用的單機完整版，涵蓋基礎的抽籤、大鐘、計分五大功能。
* `pro.html`：**Pro進階版**。具備深度模組連動、資料匯出入備份管理，且支援 WebRTC 之「IRS 即時問答」連線。

## 🌟 基礎與 Pro 核心功能導覽

**🎯 抽籤機與隨機智慧分組 (Random Picker & Auto Grouping)**
* 支援抽取號碼/姓名。能設定單次抽出數量與「不重複抽籤」。
* (Pro 版限定) 內建強大的「進階隨機分組功能」，只需輸入每組人數與是否純男純女，系統會直接算出分組結果並倒進計分板中。

**⏰ 升級版：時間管理大師 (Time Master)**
* 包含傳統的精確到秒的滿版「考試大鐘」。
* 有實用的「小組倒數計時器」，附帶 1、3、5 分鐘極速按鍵。
* (Pro 版限定) 新增輪迴式「上下課鐘」校園響鈴，以及具備布穀鳥動畫與滴答音效的「25分鐘讀書番茄鐘」。

**🏆 計分板與噪音偵測系統 (Scoreboard & Noise Tracker)**
* (核心特首) 計分板附帶**全班噪音偵測**。打開麥克風讓系統聆聽班級音量，一旦過於吵雜超過您的紅線標準（系統滑桿自訂），系統會自動懲罰扣分；如果整班維持圖書館層級的安靜數十秒，系統會自動給予正增強加分獎勵！
* (Pro 版限定) 可以點開各小組，針對組內的「每一位同學獨立加分/扣分」，個人成績會加總至整個小組成績，雙軌並行計算。

**📱 IRS WebRTC 連線即時互動系統 (IRS for Pro)**
* (Pro 版限定) 極其強大的現場互動系統。老師開通主機號碼後，底下的 30 名學生用自己的平板或手機掃描 QRCode 即可「無須安裝 APP 直接聯機入班」。
* 老師出題學生按系統回報。學生加入教室等於完成自我點名，並會把姓名與性別資料推入給抽籤池。
* 可點擊「螢幕廣播」按鍵，將老師的簡報畫面不透過投影機，用區域網私底投射到學生所有的平板畫面上。

## ⚠️ 使用須知與限制條件 (Usage Guidelines)
本系統作為一款完全前端（不需要依賴第三方大型伺服器負載）的開箱即用型軟體，為確保順利運作，請了解以下須知：

### 1. WebRTC (IRS) 最大連線人數與環境要求
* IRS 連線使用 PeerJS / WebRTC 點對點連線技術。
* **推薦人數上限**：大約在 **30 - 50 名學生之內**是最穩定的。一旦一次性連入的裝置突破 60 台，老師端電腦（主機）的瀏覽器需要大量的 CPU 及頻寬處理每一條線，可能會產生系統卡頓或斷線。
* **學校防火牆限制**：WebRTC 協定非常容易被某些中小學極嚴格的防火牆或 MIS 阻擋。若您發現「產生不出連線代碼」或「學生打入代碼一直轉圈圈進不來」，極大機率是您校內的網段封鎖了 P2P UDP 連線通訊埠。

### 2. 關於「重整頁面」導致的資料遺失
* `index.html` 基礎版不具備全域存檔能力，若不小心按下鍵盤 `F5` 重新整理頁面，所有的計分與設定將會當場歸零。
* **預防與解法**：`pro.html` 提供了解方，請務必養成良好習慣。每當班級名單與大略分數建置好後，定時去右上角的「資料管理中心」點擊 **匯出為 CSV 備份**。一旦重整了，只要點擊一次「匯入」便能瞬間還原進度！

### 3. 計分板「噪音偵測」敏感度調校
* 此功能深受老師電腦硬體影響（內建麥克風距離嘴巴多近、雜音抑制強度）。
* **使用建議**：一開始使用務必把 Threshold (達標線設定) 往右拉寬容度高一點。並先確保您瀏覽器的權限已經允許麥克風存取！

## 🔧 故障排除地雷區 (Troubleshooting)
| 症狀描述 | 行動與解法排除 |
| :------- | :--- |
| **學生無法從手機連線至 IRS (無限打轉)** | 1. 確認學生是否打錯網址與代碼。<br>2. 要求幾位連不上的學生**「關閉學校 Wi-Fi，改用自己的 4G/5G 行動網路」**。如果行動網路能登入，就確定是貴校防火牆擋住了 WebRTC。<br>如果是防火牆擋住，這套系統就難以在該教室網路推行連線。 |
| **老師畫面按「連接」跳不出 QRCode 或顯示 Error** | 通常是公用網段阻擋了對公共 STUN 伺服器的請求。老師端可以改借用手機開熱點來避開資安阻擋器。 |
| **開啟噪音系統，但音量表永遠在 0% 沒在跳？** | 您可能禁用了網頁麥克風權限。解決方案：點擊網址列最前端的鎖頭/設定符號，將麥克風權限從「封鎖」手動調整為「允許」，然後再按畫面「開啟麥克風」按鈕即可。 |
| **抽籤機無法跑「不重複抽籤」？** | 請確認您的「抽取總數」是否大於全班總人數。如果班上只剩 5 人沒被抽過，您卻設定一次抽 6 人，因為啟用「不重複」是不可能達成的，系統會報錯提示。 |

## 🚀 如何使用
1. 直接用您的個人電腦（筆電佳）透過 Chrome/Edge 瀏覽器開啟 `index.html` 或是 `pro.html`。
2. 頂部提供全功能的導覽列，一鍵即可快速在抽籤、計時、計分之間順滑切換。
3. Pro 版使用者建議在第一次建立完學生名單後，點擊右上角「資料管理」將 CSV 下載保存，之後每堂課只要匯入即可開始上課。
